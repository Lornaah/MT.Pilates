Fonctionnement :
- **Markdown** : rendu côté serveur (commonmark-java, décision Q6), HTML brut échappé comme ReactMarkdown.
- **Aperçu** : demandé au serveur.
- **Image de couverture** : téléversée dans le bucket public `announcement-images`.
- **Ciblage** : port de la vue `v_announcements_for_user` ; annonces publiées seulement, pour tous, les membres
  actifs, une liste de membres ou les membres d'un coach.
- **Lecture** : marquée au clic, depuis la page ou depuis la cloche (le panneau reste ouvert).
- **Récurrence** : enregistrée (`FREQ=…;BYDAY=…`) mais jamais appliquée, comme l'original (hors périmètre, Q10).

Règles d'accès (Q1) : gestion par le staff de la base ; lectures écrites par l'utilisateur lui-même.
