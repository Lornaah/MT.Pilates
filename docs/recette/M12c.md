# Recette M12c — Générateur de plan repas

Date : 2026-11-17. Même protocole que M1 (élève Léa présélectionnée par `?member=`).

| Étape | Écart |
|---|---|
| 1. Élève | 0,01 % |
| 2. Config | 0,01 % |
| 3. Plan (semaine générée) | 0,14 % (toast « Plan généré ») |
| 4. Courses | 0,14 % |
| 5. Envoi | 0,15 % |

## Fonctionnement
- **Algorithme** :
  - `mealPlanGenerator.ts` et `buildShoppingList` sont portés en Java (`MealPlanGenerator`) ;
  - le test `MealPlanGeneratorTest` compare le résultat Java à une référence produite en exécutant le fichier
    TypeScript d'origine sur 4 configurations : identique au repas, à la portion et à la quantité près ;
  - la semaine de l'écran 3 est aussi identique pixel près à l'original sur les données de démo.
- **Assistant** :
  - l'état (étapes, configuration, repas, courses) vit dans Alpine ;
  - génération, liste de courses et envoi passent par le serveur en JSON (`$postJson`, CSRF et toasts compris) ;
  - « Régénérer » sur un jour régénère la semaine et n'en garde que ce jour, comme l'original.
- **Envoi** :
  - un nouveau plan actif est créé pour le membre, à condition que le coach le gère (policy de `nutrition_plans`) ;
  - on arrive ensuite sur la fiche membre avec les deux toasts de l'original (« Plan repas créé », « Plan envoyé à
    l'élève »).
- **Redirection** : `/app/coach/meal-plans/generate` mène à `/app/coach/nutrition/plans/generate`.

## Écart assumé
Dans l'original, le sélecteur « Créneaux libres » s'affichait vide pour la valeur 0. C'est un défaut d'affichage du
composant Radix : la valeur restait bien 0. Ici, « 0 » s'affiche.

## Comportements conservés (à valider)
- Les préférences nutritionnelles de l'élève pré-remplissent la configuration. Les clés lues sont celles de l'original
  (`daily_kcal_target`, `macros_split`, `meals_per_day`, `allergies`, `kitchen_appliances`…). L'onboarding n'en
  remplit qu'une partie, `meals_per_day` notamment.
- La liste des élèves contient tous les profils visibles, y compris l'équipe. Un nom vide s'affiche vide.
- Le plan généré ne reçoit ni description ni dates de début et de fin.
