## Fonctionnement
- **Téléversement** :
  - le fichier part dès qu'il est choisi (clic ou glisser-déposer) ;
  - il est rangé dans le bucket privé `documents` sous un nom aléatoire ;
  - le titre est pré-rempli avec le nom du fichier s'il est vide.
- **Enregistrement** : « Titre et fichier requis » si l'un manque, comme l'original. Les membres autorisés ne sont
  conservés que pour la visibilité « Membres spécifiques ».
- **Téléchargement** :
  - passe par `/app/documents/{id}`, qui remplace les liens signés Supabase ;
  - la visibilité est vérifiée à chaque appel : le staff voit tout, un membre ne voit que « Tous les membres » ou les
    documents qui lui sont partagés ;
  - dans tout autre cas, la réponse est 404.
- **Carte « Documents partagés »** : elle exclut les documents réservés à l'équipe, comme l'original.

## Correction (Q2)
La suppression d'un document efface aussi son fichier : l'original laissait le fichier dans le bucket.
