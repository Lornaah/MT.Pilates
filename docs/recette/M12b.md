# Recette M12b — Éditeur de menu type

Date : 2026-11-17. Même protocole que M1, avec les données de M12a.

| Écran | Écart |
|---|---|
| `/app/coach/nutrition/templates/{id}` (paramètres, semaines, grille) | 0,03 % |
| `/app/coach/nutrition/templates/new` | 0,03 % |
| Popover « Ajouter » (recherche de recette) | 0,07 % |
| Popover d'un repas (type, Retirer) | 0,11 % (1 px) |

## Fonctionnement
- **État de l'éditeur** : paramètres, semaines, commentaires et repas vivent dans Alpine, comme l'état React de
  l'original.
- **Enregistrement** :
  - « Brouillon » et « Publier » envoient tout en JSON ; le serveur valide (« Titre requis ») et enregistre ;
  - une création mène à l'URL du menu avec le toast « Menu type créé » ;
  - une mise à jour reste sur place avec « Menu type mis à jour ».
- **Grille hebdomadaire** :
  - la grille est un fragment partagé (`fragments/nutrition/meal-grid`), réutilisé par l'éditeur de plan élève (M12d) ;
  - un repas ajouté recopie titre, kcal et macros de la recette ;
  - un jour sous 85 % de la cible kcal est signalé « incomplet ».
- **Suppression** : retour à l'onglet « Menus types » avec le toast « Menu type supprimé ». Les plans déjà assignés
  sont conservés.
- **Couleurs** : celles des couvertures et des types de repas sont des variables CSS (`--cover-*`, `--meal-*`).

## Écart assumé
Plus de 12 semaines est refusé avec « Un menu type compte de 1 à 12 semaines ». L'original affichait l'erreur brute de
la contrainte CHECK de la base.
