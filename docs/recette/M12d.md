# Recette M12d — Plan par membre et « Ton plan nutritionnel »

Date : 2026-11-17. Même protocole que M1. Plan actif de Léa testé dans ses deux formats :
- un plan généré : repas planifiés par jour ;
- un plan saisi à la main : aliments par repas, avec import de recette.

| Écran | Écart |
|---|---|
| `/app/nutrition` (membre, plan généré) | 0,00 % |
| `/app/nutrition` (membre, plan saisi à la main) | 0,01 % |
| `/app/coach/members/{id}/nutrition` (plan généré) | 0,02 % |
| `/app/coach/members/{id}/nutrition` (plan saisi à la main) | 0,06 % |
| Dialog « Choisir une recette » | 0,02 % |

## Fonctionnement
- **Éditeur coach** :
  - l'état vit dans Alpine, sur une grille de 7 jours × 4 repas ;
  - « Recette » copie les ingrédients avec leur provenance ;
  - « Enregistrer » met à jour le plan actif, ou en crée un.
  - Le coach doit gérer le membre (policy de `nutrition_plans`), sinon la réponse est 403.
- **Page membre** :
  - affiche le plan actif le plus récent, dans ses deux formats ;
  - suit les objectifs du jour et le masquage des macros ;
  - affiche la liste de courses, avec un bouton « Imprimer » (impression du navigateur).
- **Ajustement transverse** : un titre de carte avec une classe `text-*` reprend l'interligne de cette taille, comme
  avec twMerge. Basecoat imposait `--tw-leading: 1`. Les écrans déjà validés ont été recontrôlés sans écart nouveau.

## Correction (Q2)
L'éditeur d'origine plantait (page blanche) si un repas était stocké sous forme de texte. Ici, le repas s'affiche
« Libre ». La page membre affiche toujours ce texte.

## Comportements conservés (à valider)
- Sur un plan généré, l'éditeur coach affiche tous les repas « Libre ». L'ajout d'un aliment mélange alors les deux
  formats, comme l'original.
- « Enregistrer » réactive le plan et en fait le coach courant l'auteur.
