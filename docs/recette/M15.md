# Recette M15 — Application installable, finitions et recette globale

Date : 2026-11-17.

## Application installable (PWA)
- Manifest complété (`id`, `scope`, `lang`, icônes `purpose: any`) ; mêmes nom, couleurs et icônes que l'original.
- **Service worker** (`/sw.js`) :
  - réseau d'abord ;
  - en cas de coupure, la navigation affiche `/offline.html` (« Vous êtes hors ligne », bouton « Réessayer ») ;
  - aucune donnée de l'application n'est mise en cache.
- **« Installer l'app »** :
  - sur Android et Chrome, l'invite native du navigateur s'ouvre (`beforeinstallprompt`) ;
  - ailleurs (iOS…), le dialog d'instructions de l'original s'affiche ;
  - le bouton reste masqué quand l'application est déjà installée.
- **Vérifié avec Chrome** (`Page.getInstallabilityErrors`) : aucune erreur d'installabilité, aucune erreur de
  manifest. La page hors ligne s'affiche réseau coupé.
- La publication sur les stores reste hors périmètre.

## Finitions
- **Redirections de compatibilité** : toutes vérifiées par `CompatibilityRedirectsTest`.
  - `coach/recipes` et `coach/foods` mènent aux onglets du hub nutrition ;
  - `coach/meal-plans/generate` mène au générateur ;
  - `admin/prospects` mène à `prospects`, `admin/finance` à `money`.
- **Accessibilité** :
  - lien d'évitement « Aller au contenu principal » ;
  - libellés `aria-label` repris de l'original ;
  - focus visible des composants ;
  - premier champ des dialogs focalisé (et sélectionné, comme Radix).
- **Badges** : comme le Badge shadcn, ils peuvent rétrécir et passer à la ligne. Basecoat les figeait (`shrink-0`,
  `nowrap`), ce qui changeait le rendu sur mobile, par exemple le badge de date de l'agenda du tableau de bord.

## Passe responsive (390 px de large)
20 écrans comparés à l'original sur mobile, tous rôles confondus. Ils sont tous entre 0,00 % et 0,52 %, sauf :
- Finance (3,4 %) : uniquement les graphiques, voir M14 ;
- la première mesure de « Vidéos » (11 %) : due à une vidéo de test restée dans la base de développement, supprimée
  depuis.
