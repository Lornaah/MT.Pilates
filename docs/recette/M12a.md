## Fonctionnement
- **Filtres** : recherche, onglets et filtres sont filtrés dans le navigateur (Alpine), comme l'original. Les
  enregistrements et suppressions re-rendent la liste ; pour les recettes, les tuiles et les compteurs des onglets sont
  aussi mis à jour.
- **OpenFoodFacts** :
  - le serveur appelle directement `world.openfoodfacts.org` (client `RestClient`) et remplace la fonction edge ;
  - une erreur réseau donne « Produit introuvable » ou « Aucun résultat », comme la fonction d'origine ;
  - l'URL est paramétrable (`app.openfoodfacts.base-url`) ;
  - le User-Agent est générique (`MTPilates/1.0`).
- **Assigner un menu type** :
  - la semaine choisie est copiée dans un nouveau plan actif du membre ;
  - le compteur d'utilisation augmente et le menu remonte en tête de liste (trigger `updated_at` de l'original) ;
  - le coach doit gérer le membre (policy de `nutrition_plans`), sinon la réponse est 403.
- **Redirections** : `/app/coach/recipes` et `/app/coach/foods` mènent aux onglets du hub.
- **Liens en attente** : « Nouveau menu type », « Modifier », le générateur et « Voir » (plan d'un élève) mènent à
  des écrans des étapes M12b à M12d.
